# Commit Clout

Every year mom says we get to post how many commits we did for clout.

This year was really dumb, because people are posting their commit count while most of their repos have Claude as a co-author.

This repo lets you inflate your commit count with commits on commits on commits.

I'm not going to tell you how to use it because you shouldn't use it.

But if you do use it, don't get mad at me in Microsoft shows up at your house and throws you in a van for violating the Github T&C.
